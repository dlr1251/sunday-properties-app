# Edit property

How to edit a property you have already published.

## When you can edit

You can edit a property in **draft**, **pending**, or **published** status. If it is under review (pending), some changes may require a new approval.

## Steps

1. **Go to My properties**  
   In the dashboard, go to the properties section (or "Upload property" / "Manage properties").

2. **Select the property**  
   Find the property you want to edit and open it.

3. **Change data**  
   You can change basic info, features, photos, sale conditions, negotiation rules, and visit availability, depending on the wizard step.

4. **Save**  
   Save changes. If the property was published, changes apply according to platform rules (may require new review or publish immediately).

## Limits

- You cannot edit offers or visits already linked; only property data.
- If a negotiation is in progress, check with the team whether certain changes are allowed.
