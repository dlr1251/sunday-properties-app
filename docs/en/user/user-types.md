# User types

Roles on the platform and what each can do.

## Summary

Sunday Properties defines several user **roles**. Your role determines which sections you see and which actions you can perform.

## Roles

| Role | Description | Can | Cannot |
|------|-------------|-----|--------|
| **Regular user** | Buyer or prospect | Browse properties, manage profile and favorites, schedule visits, make offers | Manage others' properties, access agent/lawyer panels |
| **Real estate agent** | Intermediary | Publish properties, manage assigned clients, create offers on behalf of clients, view metrics | Manage legal cases, access other agents' data |
| **Lawyer** | Legal | Manage assigned legal cases, review contracts and documents, participate in negotiations, validate legal terms | Publish properties as agent, access unassigned cases |
| **Administrator** | Operations | Full access: users, permissions, publication review, audit logs, platform configuration | — |

## Verification

To **schedule visits**, **make offers**, and **publish properties** you need a **verified** profile. Identity verification is required for these flows.
