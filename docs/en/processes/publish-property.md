# Publish property

Full flow of the property publishing wizard.

## Prerequisites

- Verified profile.
- Property CLYT (or equivalent) document.
- Property photos (minimum 5, up to 20 recommended).
- Selling price defined.

## Wizard steps

### 1. Legal documents

Upload CLYT as PDF, JPG, or PNG (max 10 MB). The system extracts data (address, registration, owner, area, type, encumbrances) and prefills later steps. Review and correct if needed. Optional: administration clearance, lease, deed.

### 2. Basic info

- **Title**: Descriptive, max 100 characters.
- **Description**: Property and location details, 100–2000 characters.
- **Address**: Street, number, neighborhood, city (e.g. Medellín), optional postal code.

### 3. Features

- Type (apartment, house, office, commercial, etc.).
- Bedrooms, bathrooms, total area (m²), built area if applicable.
- Stratum (1–6), parking, floor/total floors, year built, condition.

### 4. Photos

Minimum 1, maximum 20. JPG, PNG; max 10 MB per image. Order and set the main image. Suggested order: exterior, living room, kitchen, bedrooms, bathrooms, common areas, details.

### 5. Sale conditions

- Sale price in COP.
- Accepted payment methods: cash, financing, crypto (one or more).
- Optional additional costs (administration, taxes).
- Optional special conditions (delivery timeline, appliances, etc.).

### 6. Negotiation rules

- Minimum acceptable price (e.g. % of sale price).
- Maximum closing period (days). Offers exceeding it may be rejected.
- Minimum down payment if financing is accepted.
- Toggle automatic offer validation against these rules.

### 7. Visit availability

Define weekly slots (day and start/end time) when visits can be scheduled. Required to publish.

### 8. Review and submit

Review summary, confirm, and submit for review. An admin approves publication. The owner is notified when the property becomes "published".

## Result

Property in "pending" until approval; then "published" and visible in the listing. The owner can edit, pause, or archive from the management panel.
