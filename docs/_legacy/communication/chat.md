# 💬 Guía: Sistema de Chat

Esta guía explica cómo usar el sistema de chat integrado en Sunday Properties.

## 📋 Visión General

Sunday Properties incluye un sistema de chat integrado que permite comunicación en tiempo real entre compradores, vendedores y abogados durante el proceso de transacción.

## 🎯 Tipos de Conversaciones

### Chat de Caso Legal

Cuando una oferta es aceptada y se crea un caso legal, automáticamente se crea una conversación de chat que incluye:

- **Comprador**: La persona que hizo la oferta
- **Vendedor**: El propietario de la propiedad
- **Abogado**: El abogado asignado al caso

### Chat General

También puedes tener conversaciones generales con otros usuarios de la plataforma.

## 💬 Usar el Chat

### Acceder al Chat

1. **Desde el Menú Principal**
   - Haz clic en "Mensajes" en la navegación
   - O ve a `/messages`

2. **Desde un Caso**
   - Si estás en un caso legal, hay una pestaña "Chat"
   - Haz clic para abrir la conversación del caso

### Ver Conversaciones

1. **Lista de Conversaciones**
   - Verás todas tus conversaciones activas
   - Se ordenan por última actividad
   - Indicador de mensajes no leídos

2. **Información de Cada Conversación**:
   - Nombre del otro participante
   - Último mensaje enviado
   - Fecha y hora
   - Indicador de no leídos

### Enviar Mensajes

1. **Seleccionar Conversación**
   - Haz clic en una conversación de la lista
   - Se abrirá el panel de chat

2. **Escribir Mensaje**
   - Escribe en el campo de texto
   - Puedes enviar con Enter o hacer clic en enviar

3. **Adjuntar Archivos** (si está habilitado)
   - Haz clic en el icono de adjuntar
   - Selecciona archivo
   - Espera a que se suba
   - Envía el mensaje

### Notificaciones

Recibirás notificaciones cuando:

- Recibas un nuevo mensaje
- Alguien te mencione
- Se compartan documentos importantes

## 📎 Compartir Documentos

### En Chat de Caso

1. **Documentos Generados**
   - Los abogados pueden compartir documentos generados
   - Aparecen como enlaces especiales en el chat
   - Puedes verlos directamente desde el chat

2. **Adjuntar Documentos**
   - Puedes adjuntar documentos personales
   - Formatos aceptados: PDF, JPG, PNG
   - Tamaño máximo: 10MB

## 🔔 Notificaciones en Tiempo Real

El sistema muestra notificaciones en tiempo real:

- **Mientras estás en la plataforma**: Notificaciones en pantalla
- **Mientras estás en otra página**: Notificación en la esquina
- **Email**: Recibirás email si no estás activo

## 📱 Usar en Móvil

El chat está optimizado para móvil:

- Responsive design
- Funciona en todos los navegadores móviles
- Puedes recibir notificaciones push si está habilitado

## 💡 Mejores Prácticas

### Comunicación Efectiva:

- ✅ Sé claro y profesional
- ✅ Responde en tiempo razonable (24 horas)
- ✅ Mantén el tono respetuoso
- ✅ Usa el chat para temas relevantes al caso

### Para Abogados:

- ✅ Comparte documentos importantes por chat
- ✅ Explica procesos legalmente complejos
- ✅ Mantén comunicación proactiva
- ✅ Responde preguntas rápidamente

### Para Compradores/Vendedores:

- ✅ Pregunta si algo no está claro
- ✅ Revisa documentos compartidos
- ✅ Responde a solicitudes del abogado
- ✅ Mantén comunicación activa

## ❓ Problemas Comunes

### No recibo notificaciones de mensajes

- **Solución**: Verifica configuración de notificaciones
- Revisa permisos del navegador
- Asegúrate de tener notificaciones habilitadas

### No puedo enviar mensajes

- **Solución**: Verifica conexión a internet
- Refresca la página
- Verifica que tengas acceso a la conversación

### Los mensajes no se cargan

- **Solución**: Verifica conexión a internet
- Refresca la página
- Intenta desde otro navegador
