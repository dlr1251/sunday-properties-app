# 📄 Guía: Documentos Legales

Esta guía explica cómo funcionan los documentos legales generados con IA en Sunday Properties.

## 📋 Visión General

Sunday Properties utiliza inteligencia artificial para generar documentos legales profesionales que cumplen con las normativas colombianas. Todos los documentos siguen el Código Civil Colombiano y las leyes notariales vigentes.

## 🤖 Sistema de Generación con IA

### Tecnología Utilizada

- **Modelo**: Grok-4-fast-reasoning (xAI)
- **Temperatura**: 0.3 (para consistencia en documentos legales)
- **Tokens Máximos**: 4000
- **Idioma**: Español (Colombia)
- **Estándares**: Código Civil Colombiano, Ley 1579 de 2012

### Ventajas del Sistema

- ✅ Documentos profesionales y precisos
- ✅ Cumplimiento legal automático
- ✅ Generación rápida (segundos)
- ✅ Consistencia en formato
- ✅ Inclusión automática de información del caso

## 📚 Tipos de Documentos

### 1. Carta de Intención

#### Propósito

Expresión formal de intención de compra. **NO es legalmente vinculante**, pero establece los términos básicos acordados entre comprador y vendedor.

#### Cuándo Usar

- Primera etapa después de aceptar una oferta
- Para formalizar intención antes de documentos vinculantes
- Para establecer cronograma básico de transacción

#### Contenido Típico

1. **Identificación de Partes**
   - Comprador completo
   - Vendedor completo
   - Propiedad involucrada

2. **Términos del Acuerdo**
   - Precio propuesto
   - Método de pago
   - Fecha de cierre estimada
   - Condiciones especiales

3. **Declaraciones**
   - Seriedad de intención
   - Compromiso de buena fe
   - Próximos pasos

#### Ejemplo de Uso

```
Generar Carta de Intención para:
- Propiedad: Apartamento en El Poblado
- Precio: $500,000,000 COP
- Comprador: Juan Pérez
- Vendedor: María García
- Cierre estimado: 60 días
```

### 2. Promesa de Compraventa

#### Propósito

Contrato **legalmente vinculante** que establece las obligaciones de ambas partes según el Código Civil Colombiano (Art. 89 Ley 153 de 1887).

#### Cuándo Usar

- Después de llegar a acuerdo final
- Antes de escritura pública
- Para establecer compromiso legal firmado

#### Contenido Legal Requerido

1. **Identificación Completa**
   - Comprador: nombre, cédula, dirección
   - Vendedor: nombre, cédula, dirección
   - Propiedad: descripción completa, matrícula

2. **Términos de Venta**
   - Precio total
   - Forma de pago (efectivo/financiamiento/mixto)
   - Cronograma de pagos
   - Fecha de cierre específica

3. **Obligaciones del Comprador**
   - Pago en tiempos acordados
   - Documentación requerida
   - Inspecciones necesarias

4. **Obligaciones del Vendedor**
   - Entrega de propiedad en condiciones acordadas
   - Documentación legal completa
   - Transferencia de dominio

5. **Cláusulas Legales**
   - Penalidades por incumplimiento
   - Resolución de conflictos
   - Notarización
   - Jurisdicción

#### Aspectos Legales Importantes

- Según Código Civil Colombiano, la promesa es vinculante
- Requiere notarización para efecto completo
- Puede tener penalidades por incumplimiento
- Establece plazos y condiciones claras

---

### 3. Minuta de Escritura Pública

#### Propósito

Documento preparado para presentar en notaría. Cumple con **Ley 1579 de 2012** (Ley Notarial Colombiana) y facilita el proceso de escrituración.

#### Cuándo Usar

- Cuando todo está listo para escrituración
- Antes de ir a notaría
- Para acelerar proceso notarial

#### Contenido Notarial

1. **Datos Notariales**
   - Notaría donde se realizará
   - Fecha de presentación
   - Número de minuta

2. **Identificación Completa de Partes**
   - Comprador: datos completos de identidad
   - Vendedor: datos completos de identidad
   - Representantes legales si aplica

3. **Descripción Registral**
   - Matrícula inmobiliaria
   - Descripción completa según certificado
   - Área total y construida
   - Linderos y ubicación

4. **Documentación de Pago**
   - Certificado de tradición
   - Paz y salvo de impuestos
   - Paz y salvo de administración
   - Certificados de no deuda

5. **Transferencia de Dominio**
   - Declaración de dominio
   - Transferencia de propiedad
   - Pago de impuestos de transferencia

#### Cumplimiento Legal

- Sigue formato estándar notarial colombiano
- Incluye todas las declaraciones requeridas
- Listo para firma ante notario
- Facilita proceso de registro

---

### 4. Otrosí (Modificación)

#### Propósito

Documento para modificar un contrato existente. Referencia al documento original y especifica exactamente qué se modifica.

#### Cuándo Usar

- Para modificar términos acordados
- Agregar condiciones adicionales
- Aclarar términos específicos
- Cambiar plazos o condiciones

#### Estructura

1. **Referencia al Contrato Original**
   - Fecha del contrato original
   - Partes involucradas
   - Número de documento

2. **Modificaciones Específicas**
   - Qué cláusulas se modifican
   - Nuevo texto de las cláusulas
   - Justificación de cambios

3. **Mantenimiento de Cláusulas**
   - Las cláusulas no mencionadas se mantienen
   - Validez del contrato original preservada

## 🔄 Proceso de Generación

### Paso 1: Seleccionar Tipo de Documento

1. Ve al caso en tu dashboard
2. Pestaña "Documentos"
3. Haz clic en "Generar Nuevo Documento"
4. Selecciona el tipo de documento

### Paso 2: IA Genera el Documento

1. **El sistema procesa**:
   - Información completa del caso
   - Datos de las partes
   - Detalles de la oferta aceptada
   - Información de la propiedad

2. **Generación con IA**:
   - Usa plantillas legales profesionales
   - Incluye toda la información relevante
   - Sigue normativas colombianas
   - Formato profesional

3. **Tiempo de Generación**:
   - Generalmente 10-30 segundos
   - Depende de complejidad
   - Puedes ver progreso en pantalla

### Paso 3: Revisar y Editar

1. **Revisar Documento Generado**:
   - Lee completo el documento
   - Verifica información
   - Revisa términos legales

2. **Editar si es Necesario**:
   - Puedes editar cualquier sección
   - Agregar o quitar cláusulas
   - Modificar términos específicos

3. **Guardar Versión**:
   - Guarda el documento
   - Se crea versión 1.0
   - Puedes generar nuevas versiones

### Paso 4: Compartir y Firmar

1. **Compartir con Partes**:
   - Comparte en chat del caso
   - Las partes reciben notificación
   - Pueden revisar el documento

2. **Proceso de Firma**:
   - Solicitar firmas cuando esté listo
   - Cada parte firma digitalmente
   - Se genera copia firmada

3. **Versión Final**:
   - Cuando todas las partes han firmado
   - Documento pasa a "Firmado"
   - Se archiva en el caso

## 📋 Gestión de Versiones

### Control de Versiones

1. **Versiones Numeradas**:
   - Versión 1.0, 1.1, 2.0, etc.
   - Historial completo de cambios
   - Comparación entre versiones

2. **Historial de Cambios**:
   - Quién hizo cambios
   - Cuándo se hicieron
   - Qué se modificó

3. **Versión Final**:
   - Una vez firmado, se marca como final
   - No se puede modificar después
   - Se genera copia archivada

## ❓ Preguntas Frecuentes

### ¿Los documentos son legalmente válidos?

Los documentos siguen las normativas colombianas y son válidos. Sin embargo, algunos documentos requieren notarización para efecto completo. Siempre consulta con tu abogado.

### ¿Puedo modificar un documento después de generarlo?

Sí, puedes editar documentos antes de compartirlos. Una vez firmado por todas las partes, no se puede modificar.

### ¿Qué pasa si hay un error en el documento?

Puedes editar el documento antes de compartirlo. Si ya se compartió, crea una nueva versión con las correcciones.

### ¿Cómo sé qué tipo de documento necesito?

Tu abogado te guiará sobre qué documentos necesitas en cada etapa del proceso. Generalmente:
- Carta de Intención: Primera etapa
- Promesa de Compraventa: Después de acuerdo final
- Minuta: Antes de escrituración
