# 👤 Guía: Dashboard de Usuario

Esta guía explica cómo usar tu dashboard personal como usuario de Sunday Properties.

## 📋 Visión General

Tu dashboard es tu centro de control personal donde puedes ver todas tus actividades, propiedades favoritas, ofertas activas y más.

## 🎯 Secciones del Dashboard

### Overview (Resumen)

Visión general de tu actividad:

- **Propiedades Favoritas**: Propiedades que has guardado
- **Ofertas Activas**: Ofertas que has hecho
- **Visitas Programadas**: Próximas visitas
- **Casos Activos**: Casos legales en progreso

### Mis Propiedades Favoritas

1. **Ver Favoritos**
   - Lista de propiedades guardadas
   - Acceso rápido a detalles
   - Remover de favoritos

2. **Agregar a Favoritos**
   - Botón en página de propiedad
   - Se guarda automáticamente
   - Sincronizado en todos tus dispositivos

### Mis Ofertas

1. **Ofertas Activas**
   - Ofertas pendientes de respuesta
   - Ofertas aceptadas
   - Ofertas rechazadas
   - Historial completo

2. **Detalles de Oferta**:
   - Propiedad ofertada
   - Precio ofertado
   - Estado actual
   - Próximos pasos

### Mis Visitas

1. **Visitas Programadas**
   - Próximas visitas confirmadas
   - Fecha y hora
   - Dirección de la propiedad
   - Instrucciones

2. **Historial de Visitas**
   - Visitas completadas
   - Feedback dado
   - Documentos desbloqueados

### Mis Casos

1. **Casos Activos**
   - Casos legales en progreso
   - Estado de cada caso
   - Documentos pendientes
   - Chat con abogado

2. **Información del Caso**:
   - Propiedad involucrada
   - Otra parte (comprador/vendedor)
   - Abogado asignado
   - Próximos pasos

## 📊 Estadísticas Personales

### Métricas Disponibles

- Total de propiedades visitadas
- Total de ofertas realizadas
- Tasa de éxito de ofertas
- Propiedades en favoritos

- Configurar notificaciones

### Preferencias
