# Firmar documentos

Revisar y firmar documentos legales tras aceptar una oferta.

## Cuándo aplica

Cuando se **acepta una oferta o contraoferta**, se inicia el proceso legal: se crea un caso, se asigna un abogado y se generan documentos (contratos, cartas de intención, etc.). Como comprador o vendedor, tendrás que revisar y firmar según indique el abogado.

## Pasos

1. **Notificación**  
   Recibirás notificaciones cuando haya documentos pendientes de revisión o firma.

2. **Acceder al caso**  
   Desde el dashboard o "Mis negociaciones", entra en el caso asociado a la oferta aceptada.

3. **Revisar documentos**  
   El abogado sube o genera documentos. Revisa cada uno en la sección de documentos del caso.

4. **Firmar**  
   Cuando el documento esté listo para firma, sigue las indicaciones en pantalla (firma electrónica, aceptación de términos, etc.).

5. **Chat del caso**  
   Usa el chat del caso para dudas y coordinación con el abogado y la otra parte.

## Resultado

Documentos generados, revisados y firmados según corresponda. Trazabilidad en notificaciones y en el historial del caso.
