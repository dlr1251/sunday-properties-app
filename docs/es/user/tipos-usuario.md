# Tipos de usuario

Roles en la plataforma y qué puede hacer cada uno.

## Resumen

Sunday Properties define varios **roles** de usuario. Tu rol determina qué secciones ves y qué acciones puedes realizar.

## Roles

| Rol | Descripción | Puede | No puede |
|-----|-------------|-------|----------|
| **Usuario regular** | Comprador o interesado | Explorar propiedades, gestionar perfil y favoritos, agendar visitas, hacer ofertas | Gestionar propiedades ajenas, acceder al panel de agentes/abogados |
| **Agente inmobiliario** | Intermediario | Publicar propiedades, gestionar clientes asignados, crear ofertas en nombre de clientes, ver métricas | Gestionar casos legales, acceder a datos de otros agentes |
| **Abogado** | Legal | Gestionar casos legales asignados, revisar contratos y documentos, participar en negociaciones, validar términos legales | Publicar propiedades como agente, acceder a casos no asignados |
| **Administrador** | Operación | Acceso completo: usuarios, permisos, revisión de publicaciones, logs de auditoría, configuración de plataforma | — |

## Verificación

Para **agendar visitas**, **hacer ofertas** y **publicar propiedades** necesitas tener tu perfil **verificado**. La verificación de identidad es obligatoria en estos flujos.
