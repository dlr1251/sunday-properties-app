# Registro

Cómo crear una cuenta en Sunday Properties.

## Pasos

1. **Ir a Registro**  
   En la página de inicio, haz clic en "Registrarse" o "Crear cuenta".

2. **Completar datos**  
   - Correo electrónico  
   - Contraseña (cumplir requisitos de seguridad)  
   - Nombre completo  
   - Teléfono (opcional pero recomendado)  
   - Tipo de usuario (comprador, vendedor, agente, etc.) si se solicita

3. **Aceptar términos**  
   Acepta los términos y condiciones y la política de privacidad.

4. **Confirmar correo**  
   Revisa tu bandeja y haz clic en el enlace de confirmación que envía la plataforma.

5. **Iniciar sesión**  
   Una vez confirmado, inicia sesión con tu correo y contraseña.

## Después del registro

- Completa tu **perfil** (foto, datos de contacto).
- Solicita la **verificación de identidad** para poder agendar visitas, hacer ofertas y publicar propiedades.
